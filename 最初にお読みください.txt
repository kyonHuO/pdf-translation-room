PDF翻訳室 Mark.Ⅱ

英語のPDFを日本語に翻訳し、日本語版と左右見開きの対訳版を作るMacアプリです。
PDFの選択から保存まで、専用ウィンドウで操作できます。

1. ZIPを解凍し、PDF翻訳室 Mark.Ⅱ.appを開きます。
2. 初めて使う場合は「セットアップ」を押します。ライブラリやフォントを
   ダウンロードするため、インターネット接続が必要です。数分かかることがあります。
3. 右上の「翻訳設定」で、使いたい翻訳先を選びます。
4. 英語のPDFを選んで「翻訳する」を押します。
5. 「日本語版」か「対訳版」を選んで保存します。

翻訳先の選び方

・Codex
  各自のChatGPTアカウントのCodex利用枠を使います。
  Codex CLIがなければ、画面から公式CLIをセットアップできます。
  ChatGPTへの初回ログイン時は公式のサインイン画面がブラウザで開きます。

・OpenAI互換API
  サービスが指定する Base URL、モデル名、APIキーを入力します。
  例として、OpenAI API の Base URL は https://api.openai.com/v1 です。
  Base URLには末尾の /chat/completions を入れないでください。
  接続先にはOpenAI互換の Chat Completions API が必要です。
  料金や利用上限は接続先によります。キーはアプリを閉じるまでメモリに保持します。

動作条件
macOS 14以降。Appleシリコン用とIntel用の実行ファイルを同梱しています。
実機での動作確認はAppleシリコン搭載Macで行いました。
文字を選択できる英語PDFに対応します。上限は50 MBです。
画像だけのPDFは、あらかじめOCRで文字を選択できるようにしてください。

翻訳する本文は選んだ翻訳先に送信されます。PDFの解析と組み直しはお使いのMacで行います。
